# 🚀 DISTRIBUTED RECOVERY POOL
### 🚀 GUI HashPool — Graphical Application for Distributed Computing Pool Management
A graphical application (GUI) is being developed for managing brute-force processes and interacting with a distributed computing task pool.
The application allows users to select available tasks from the pool, run computations on NVIDIA and other GPUs, monitor progress, view statistics, and manage operational parameters.
### ⚡ Main Features
#### 🟢 CUDA Tab (NVIDIA)
•	Select available tasks from the pool.
•	Choose NVIDIA GPUs for computation.
•	Start, stop, and control the computation process.
#### 🔵 OpenCL Tab (AMD, Intel, and others)
•	Select available tasks from the pool.
•	Choose compatible GPUs for computation.
•	Start, stop, and control the computation process.
#### 📊 Monitoring Tab
•	Visualize search ranges already processed by the pool.
•	Track overall task progress.
•	Get up-to-date information about the state of the computing pool.
#### 🌐 Network Tab 🔒 Premium License
•	View user status in the pool.
•	Display personal contribution to the total computation volume.
•	Information about estimated rewards.
•	View additional statistics and data received from the pool.
#### ⚙️ Settings Tab
•	Configure CUDA/OpenCL computation parameters.
•	Enter and submit a personal activation key.
#### 🔐 Licenses and Access
The application provides different levels of access to its features.
#### ⭐ A Premium License is required for:
•	Accessing the Hashes room with corresponding computational tasks.
•	Using the Network tab, including viewing personal statistics, pool contribution, and estimated rewards.
•	Other features are available according to the relevant licensing terms.
#### ▶️ Launching the Application
To start, simply double-click the HashPool.exe file. The application will open with a graphical interface, with no need to use the command line.

💻 The main goal of the project is to provide distributed computing pool participants with a convenient tool for managing GPU computations without the need to use the command line.
All core features are combined in a single graphical interface: from task selection and hardware configuration to progress monitoring and viewing results.

#### 🔧 The project is under development. The application's functionality will be gradually expanded.
